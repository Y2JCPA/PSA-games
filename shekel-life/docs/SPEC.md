# SHEKEL LIFE — Product Specification & Build Brief

**Financial Literacy Game for Kids**
**Co-branded: Philip Stein & Associates | Blue & White Finance**
**Version 1.0 | March 2026**

## 1. Project Overview

Shekel Life is a mobile-first financial literacy game for Anglo English-speaking kids in Israel, ages 6-17. Kids play solo through age-appropriate storylines set in Israeli life, making real money decisions with real consequences.

### One-Line Pitch
A simulation game where Israeli kids earn, save, spend, and give in shekalim — and learn what happens when they get it wrong.

### Core Design Principles
- Real consequences: Bad financial decisions set you back in the game
- Age-appropriate storylines: Four distinct levels
- Israeli context throughout: Prices in shekalim, Israeli institutions, yom tov cycles
- Gender choice: Every level offers a boy or girl character
- Language toggle: English/Hebrew switchable at any point
- Progression system: Badges and milestones reward smart decisions
- Maaser as optional education: Presented as a real budget option, never forced

## 2. Game Levels

### Level 1: The Little Saver (Ages 6-8)
- Characters: Yoni (boy) / Yael (girl)
- Income: Fixed grandparent gifts
- Core mechanic: Virtual makolet shopping

### Level 2: The School Year Budget (Ages 9-11)
- Characters: Dov (boy) / Shira (girl)
- Income: Weekly pocket money
- Core mechanic: Weekly budget dashboard

### Level 3: The Part-Time Worker (Ages 12-14)
- Characters: Ari (boy) / Michal (girl)
- Income: Part-time job
- Core mechanic: Monthly income/expense simulation

### Level 4: The Road to Independence (Ages 15-17)
- Characters: Noam (boy) / Noa (girl)
- Income: Bank account, first job
- Core mechanic: Full budget + investing module

## 3. MVP Build Order

- **Phase 1:** Level 1 fully built and playable
- **Phase 2:** Level skeleton for all four levels with Level 2 content
- **Phase 3:** Levels 3 and 4 content fill-in

## 4. Badge System

| Badge | Awarded For |
|-------|------------|
| First Save | Setting aside money for the first time |
| Goal Getter | Reaching a savings goal |
| Tzedakah Star | Allocating maaser for three consecutive periods |
| Planner Pro | Navigating a Yom Tov week without going red |
| No Impulse! | Saving over impulse buy three times |
| Investor Badge | Completing Level 4 investing module |
| Shekel Legend | Completing all four levels with positive balance |
